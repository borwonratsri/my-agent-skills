# Example Custom Skill

This is a template demonstrating how to create your own custom Antigravity skills.

## When to use this skill
Describe the scenarios, triggers, and user requests that should cause this skill to be invoked.
You can also invoke it directly via slash command: `/example-custom-skill`

## Instructions for the Agent
1. **Step 1: Understand the Goal**
   - Read the user input and analyze the requirements.
2. **Step 2: Execute Actions**
   - Follow the specified workflow, run tools or commands as needed.
3. **Step 3: Confirm and Report**
   - Provide a clear, concise summary of the result.
