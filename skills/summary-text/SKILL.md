# Summary Text: บริการสรุปความทางการระดับผู้บริหาร

ทักษะสำหรับการย่อย สรุป และเรียบเรียงเนื้อหาจากข้อความยาว บันทึกการประชุม รายงานทางเทคนิค หรืออีเมล ให้กลายเป็นบทสรุปที่กระชับ ชัดเจน เป็นทางการ และพร้อมนำเสนอผู้บริหารหรือทีมงานระดับ C-Level / Management

> **Single Source of Truth**: ยึดโครงสร้างและตารางมาตรฐานจาก `~/.gemini/config/knowledge/exec-templates/exec-bluf-template.md`

## Trigger Scenarios
- Slash command: `/summary-text`
- ผู้ใช้สั่ง: "สรุปข้อความนี้ให้หน่อย", "ทำ Executive Summary", "ย่อยเนื้อหานี้ให้กระชับเป็นทางการ", "สรุปบันทึกการประชุม"

## รูปแบบโครงสร้างบทสรุป (Executive Template — ตาม `exec-bluf-template.md`)

1. **สรุปประเด็นหลัก (Executive Overview — BLUF)**:
   - 2-3 ประโยคสรุปหัวใจสำคัญของเรื่องทั้งหมด ผลกระทบ และสิ่งที่ต้องการให้ตัดสินใจ พร้อมระบุสถานะ (`Green / Amber / Red`)
2. **สาระสำคัญและตัวเลขหลัก (Key Insights & Metrics)**:
   - จุดสำคัญ 3-5 ข้อ พร้อมตัวเลข เปอร์เซ็นต์ หรือไทม์ไลน์ที่ยืนยันแล้ว (และระบุ Missing / Unverified Data หากมี)
3. **ความเสี่ยงและทางเลือกที่ต้องตัดสินใจ (Risks & Options)**:
   - ตารางหรือสรุปอุปสรรค ความเสี่ยง ผลกระทบ และทางเลือกพร้อมข้อเสนอ `(Recommended)` (ถ้ามี)
4. **แผนปฏิบัติการ (Action Items)**:
   - ตารางระบุ: **งานที่ต้องทำ (Task)**, **ผู้รับผิดชอบ (Owner)**, **กำหนดส่ง (Deadline)**, และ **Status / Dependency**

## Instructions for the Agent
1. อ่าน `~/.gemini/config/knowledge/exec-templates/exec-bluf-template.md` เพื่อคงรูปแบบตารางและโครงสร้างให้เป็นมาตรฐานเดียวกัน
2. วิเคราะห์ข้อความต้นฉบับอย่างละเอียด คัดกรองส่วนขยายและรายละเอียดปลีกย่อยออก โดยรักษาตัวเลข ชื่อผู้รับผิดชอบ และวันที่ให้ตรงตามต้นฉบับ
3. จัดลำดับความสำคัญจากเรื่องที่กระทบต่อเป้าหมายมากที่สุดขึ้นก่อน
4. ใช้ภาษาทางการ กระชับ ชัดเจน ตรงประเด็น ปราศจากคำฟุ่มเฟือยและไม่ใส่ emoji ในเอกสารทางการ
