# Website Design & Prototyping Skill

ออกแบบ พัฒนา และสร้างต้นแบบหน้าเว็บไซต์ (Web UI/UX Design) ระดับมืออาชีพ ครอบคลุมตั้งแต่ Wireframing, Information Architecture, Component System, ไปจนถึงโค้ด HTML/CSS/Tailwind/React ที่พร้อมใช้งานจริง

## Trigger Scenarios
- Slash command: `/website-design`
- ผู้ใช้สั่ง: "ออกแบบหน้าเว็บให้หน่อย", "ทำ UI/UX หน้า Landing Page", "สร้างเว็บ Dashboard สวยๆ", "Design responsive website"

## กระบวนการออกแบบและมาตรฐาน UI/UX

1. **Information Architecture & Layout Strategy**:
   - Navigation: Sticky Header, Clean Brand Logo, Clear Menu, Prominent CTA Button.
   - Hero Section: Headline คมชัด, Subtitle ขยายความน่าสนใจ, Primary & Secondary Action, Visual Banner / Mockup.
   - Social Proof & Trust: Logos ลูกค้า, Testimonials, สถิติความสำเร็จ.
   - Feature Grid: Card layout แบบ 3 คอลัมน์ พร้อมไอคอน Lucide, หัวข้อ และคำอธิบายที่อ่านง่าย.
   - Call to Action & Footer: ฟุตเตอร์จัดหมวดหมู่ลิงก์ ลิขสิทธิ์ และโซเชียลมีเดีย.

2. **Responsive & Mobile-First**:
   - รองรับ Breakpoints มาตรฐาน: Mobile (`<640px`), Tablet (`768px`), Desktop (`1024px`), Wide (`1280px+`).
   - Touch targets สำหรับมือถือไม่เล็กกว่า 44x44px.

3. **Modern Styling Principles**:
   - ใช้ Tailwind CSS พร้อม CSS Variables สำหรับ Dynamic Theming (Light/Dark mode).
   - Glassmorphism & Elevation: Subtle backdrop blur, soft border glows, natural shadows (`shadow-sm`, `shadow-xl`).
   - Typography: Inter, Plus Jakarta Sans, หรือ Prompt สำหรับภาษาไทย.

## Instructions for the Agent
1. รับฟังโจทย์ กลุ่มเป้าหมาย และโทนของแบรนด์จากผู้ใช้
2. วางโครงสร้างหน้าเว็บ (Section Breakdown)
3. ส่งมอบผลงานเป็นโค้ดที่สามารถรันได้ทันที (HTML/Tailwind หรือ React/Vite Component) หรือ Artifact Interactive Preview
